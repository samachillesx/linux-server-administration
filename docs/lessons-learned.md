# Lessons Learned

## Linux Administration

This project improved my understanding of Linux users, groups,
permissions, services, processes, networking, and logs.

## Security

I learned that SSH should be secured before exposing a server
for remote administration.

I also learned the importance of allowing only required ports
through the firewall.

## Troubleshooting

I learned to troubleshoot services systematically rather than
immediately restarting them.

My troubleshooting workflow became:

1. Check service status
2. Check listening ports
3. Check firewall rules
4. Check configuration
5. Inspect logs
6. Apply the fix
7. Verify the result

## Automation

Bash scripts were used to automate repetitive administrative tasks,
including server health checks and backups.

## DevOps Connection

This project established the Linux and networking fundamentals
required for later work with Docker, Kubernetes, Terraform,
CI/CD, and cloud infrastructure.
